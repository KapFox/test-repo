# Автономный RPA-агент с LLM-оркестрацией

Автономный агент на базе искусственного интеллекта, который анализирует экран через скриншоты, принимает решения с помощью LLM и выполняет действия в браузере.

## Возможности

### 🧠 LLM-оркестрация
- **Анализ экрана**: Агент получает скриншоты и анализирует их через мультимодальный LLM API
- **Принятие решений**: LLM определяет следующие действия на основе визуального анализа
- **Проактивность**: Агент действует самостоятельно, не требуя постоянных указаний

### 🛠️ Доступные инструменты
- `click_at_coordinates` - Клик в указанные координаты
- `type_text` - Ввод текста в поле
- `press_key` - Нажатие клавиш
- `scroll_page` - Прокрутка страницы
- `navigate_to_url` - Переход по URL
- `save_to_memory` - Сохранение в долговременную память
- `query_memory` - Запрос к памяти
- `wait_and_observe` - Ожидание и наблюдение

### 🧠 Система памяти
- **Краткосрочная память**: Последние 100 событий сессии
- **Долгосрочная память**: Важные воспоминания с приоритетами
- **Консолидация**: Структурирование памяти во время циклов сна
- **Поиск**: Поиск воспоминаний по содержимому, категории, приоритету

### 😴 Циклы сна
- **Ночная обработка**: В заданное время (по умолчанию 3:00) агент запускает цикл сна
- **Консолидация памяти**: LLM обрабатывает воспоминания, выделяет важное
- **Извлечение уроков**: Агент сохраняет извлеченные паттерны и уроки
- **Очистка шума**: Удаление маловажных данных из краткосрочной памяти

## Установка

```bash
# Установите зависимости
pip install -r requirements.txt

# Установите браузеры Playwright
playwright install chromium
```

## Настройка

### Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `LLM_API_KEY` | API ключ для LLM (OpenAI) | - |
| `START_URL` | Стартовый URL агента | `https://www.google.com` |
| `SLEEP_HOUR` | Час для цикла сна (0-23) | `3` |
| `AGENT_LOOP_DELAY` | Задержка между итерациями (сек) | `5` |

### Пример .env файла

```bash
LLM_API_KEY=sk-your-api-key-here
START_URL=https://www.google.com
SLEEP_HOUR=3
AGENT_LOOP_DELAY=5
```

## Использование

### Базовый запуск

```python
from main import AutonomousAgent
import asyncio

async def run():
    agent = AutonomousAgent(headless=False)
    await agent.initialize()
    
    # Установить задачу (опционально)
    await agent.set_task("Найти информацию о Python и сохранить важные ссылки")
    
    # Запустить автономный цикл
    await agent.run_autonomous_loop(max_iterations=10)
    
    await agent.shutdown()

asyncio.run(run())
```

### Через командную строку

```bash
python main.py
```

## Цикл работы агента

1. **Скриншот**: Делается снимок текущего экрана
2. **Анализ**: LLM анализирует изображение и контекст задачи
3. **Решение**: Определяются следующие действия с координатами
4. **Выполнение**: Агент выполняет действия через Playwright
5. **Память**: Результаты сохраняются в память с приоритетом
6. **Повтор**: Цикл повторяется через заданный интервал

## Режимы работы

### Headless / Windowed
- `headless=False` (по умолчанию): Браузер виден для отладки
- `headless=True`: Невидимый режим для продакшена

### Итерации
- `max_iterations=10`: Ограниченное количество циклов
- `max_iterations=None`: Бесконечная работа до прерывания

## Безопасность

⚠️ **Важные замечания**:
- Не храните API ключи в коде, используйте переменные окружения
- Агент имеет доступ к вашему браузеру - запускайте в контролируемой среде
- Координаты кликов определяются LLM - возможен непредсказуемый行为
- Рекомендуется запускать в виртуальной машине или контейнере

## Расширение функциональности

### Добавление новых инструментов

1. Определите инструмент в `llm_orchestrator.py` в методе `_define_tools()`
2. Реализуйте обработку в `main.py` в методе `_execute_tool()`

### Настройка промптов

Измените `system_prompt` в `llm_orchestrator.py` для адаптации поведения агента.
